préparer la Raspberry Pi

de la carte SD vierge au premier « i2cdetect »

Système, accès à distance, bus I²C, PWM matérielle, caméras, environnement Python et kit du banc : une installation propre, reproductible et notée, pour ne jamais se demander « mais comment j'avais fait ? ».

à la fin de cette page, tu auras…

  • une Raspberry Pi 5 à jour, accessible en SSH depuis ton PC ;
  • I²C, PWM matérielle et caméras activés et vérifiés ;
  • un environnement Python isolé avec le kit banclaser installé ;
  • une méthode de travail : coder sur PC, tester sur simulateur, déployer sur la Pi avec git.

1installer le système

  1. Avec Raspberry Pi Imager sur ton PC : choisis « Raspberry Pi 5 », « Raspberry Pi OS (64-bit) » (la version « Lite » suffit si tu travailles en SSH).
  2. Dans les réglages avancés de l'Imager : nom d'hôte (par exemple banc-laser), utilisateur et mot de passe, Wi-Fi, SSH activé, fuseau horaire.
  3. Insère la carte, branche l'alimentation officielle 27 W (une alimentation trop faible provoque des plantages aléatoires).
ssh kouthieye@banc-laser.local
sudo apt update && sudo apt full-upgrade -y
sudo reboot

2activer les interfaces

# I²C (et SPI si besoin) : Interface Options
sudo raspi-config
# outils de diagnostic I²C
sudo apt install -y i2c-tools
i2cdetect -y 1          # doit afficher 48, 49 et 60 une fois la carte branchée

PWM matérielle (pont en H du Peltier) : ajoute l'overlay dans /boot/firmware/config.txt, puis redémarre.

# deux canaux PWM matériels sur GPIO12 et GPIO13
dtoverlay=pwm-2chan,pin=12,func=4,pin2=13,func2=4

Sur la Pi 5, la gestion des PWM passe par la puce RP1 : vérifie dans la documentation de la bibliothèque rpi-hardware-pwm le numéro de « chip » à utiliser et teste à l'oscilloscope que les deux sorties fonctionnent à 20 kHz.

Caméras : la Pi 5 a deux connecteurs caméra (22 broches) ; utilise des câbles adaptés. Les caméras officielles sont détectées automatiquement.

rpicam-hello --list-cameras
rpicam-still -o essai.jpg --camera 0
sudo apt install -y python3-picamera2

3Python et le kit du banc

spécificités de la Raspberry Pi 5

  • RPi.GPIO ne fonctionne pas sur la Pi 5 : on utilise gpiozero (avec le pilote lgpio) — c'est ce que fait le kit.
  • picamera2 s'installe par apt ; pour l'utiliser dans un environnement virtuel, crée-le avec --system-site-packages.
sudo apt install -y git python3-venv python3-dev
git clone https://github.com/kouthieye-thiaw/carnet-photonique.git
cd carnet-photonique/projet-banc
python3 -m venv --system-site-packages .venv
source .venv/bin/activate
pip install -e ".[dev,pi]"
pytest                     # les tests tournent aussi sur la Pi

Ajoute ton utilisateur aux groupes i2c et gpio si un accès est refusé (sudo usermod -aG i2c,gpio $USER, puis reconnecte-toi).

4la méthode de travail

  1. Sur ton PC : tu codes une fonction, tu lances pytest sur le simulateur jusqu'au vert.
  2. git : git add, git commit -m "pilote ADS1115", git push.
  3. Sur la Pi : git pull, puis essai sur le vrai matériel (en commençant par les commandes de lecture, jamais par le laser).
  4. VS Code avec l'extension « Remote - SSH » permet aussi d'éditer directement sur la Pi.

tiens un journal d'installation

Dans ton carnet (journal de bord) : version du système, lignes ajoutées à config.txt, paquets installés, problèmes rencontrés et solutions. Une installation documentée se refait en 30 minutes ; une installation « de mémoire » prend une journée.

à retenir

  • Raspberry Pi OS 64 bits, SSH, alimentation 27 W.
  • I²C via raspi-config ; PWM via dtoverlay ; caméras via rpicam/picamera2.
  • Pi 5 : gpiozero + lgpio, pas RPi.GPIO ; venv avec --system-site-packages.
  • Coder sur PC + simulateur, déployer avec git.

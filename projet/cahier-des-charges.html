mon banc de test laser, de A à Z

Un banc qui caractérise une diode laser comme en production : L-I-V, température, spectre, faisceau, M², polarisation, bruit — piloté par une Raspberry Pi, codé en Python par toi, et sûr par conception.

dans ce module, tu vas…

  • spécifier ce que le banc doit mesurer, avec quelle précision et dans quelles conditions de sécurité ;
  • choisir et acheter le matériel, puis câbler et tester l'électronique ;
  • monter et aligner l'optique ;
  • coder les pilotes, les séquences de mesure, l'analyse et le rapport (le kit Python est fourni, le code c'est toi) ;
  • valider le banc par étalonnage et le documenter comme un vrai moyen de test.

3exigences

sécurité

Diode de classe 3R. Capot, interlock câblé (clé, arrêt d'urgence, capot), voyant, relais de court-circuit, limite de courant matérielle, chien de garde, poste ESD, lunettes EN 207.

automatisation

Une commande lance une séquence complète et produit les données brutes (CSV), les figures et un rapport. Aucune valeur recopiée à la main.

traçabilité

Chaque fichier contient : date, diode, n° de série, température, configuration, version du code, instrument de référence et date d'étalonnage.

modularité

Chaque sous-ensemble se teste seul ; le code tourne aussi sur le banc simulé ; la configuration est dans un fichier, pas dans le code.

coût

Version économique ≈ 400 à 500 € (hors instruments empruntés) ; la sécurité ne se négocie pas.

maintenabilité

Documentation (schémas, procédures, code commenté, tests), pièces de rechange identifiées, journal de bord.

pourquoi ce projet compte pour ta carrière

C'est la version miniature des bancs de test des fabricants de lasers : même logique de mesure, de sécurité, de traçabilité et d'automatisation. Documenté et publié, il devient une pièce de ton portfolio que tu peux montrer en entretien (stage, alternance, emploi).

à retenir

  • 8 familles de mesures, chacune avec sa méthode et sa précision visée.
  • Sécurité par conception : matérielle d'abord, logicielle en plus.
  • On commence à coder sur le simulateur pendant que le matériel arrive.
